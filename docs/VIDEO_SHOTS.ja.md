## 撮り方 (内蔵レコーダー)

MAOに内蔵したウィンドウレコーダーで撮る (アプリのウィンドウだけが映る。デスクトップ・通知・
Dockは映らない。録画中はオレンジの疑似カーソルとRECバッジが表示される)。

- 録画開始はClaude Code側から操作するので、**「シーン◯、いくよ」と言うだけでよい**。
  5秒後に録画が始まり、指定秒数で自動停止・mp4化される (`~/Desktop/mao-demo/raw/`)。
- 撮る前にウィンドウをできるだけ大きく (フルスクリーン推奨)。
- 言語は日本語UIのまま (英語版は後日UIを切り替えて撮り直す)。

## シーン一覧 (素材は長めに撮って編集で切る)

| # | 秒数 | 操作 | 見せたいもの |
|---|---|---|---|
| 1 | 15s | 操作なし。エージェント2体以上が稼働中の樹形図を映す | **フォルダが光っている**。稼働数バッジ (2/3) |
| 2 | 20s | 光っている陣地をクリック → 展開 → 中のエージェントカードを眺める | クリックで中が見える。カードの「今やっていること」 |
| 3 | 20s | 付箋を貼る → やることを書く → エージェントカードにドラッグして重ねる | 「貼る→渡す」が3操作で終わる |
| 4 | 15s | 付箋に結果の要約が書き込まれるところ (シーン3の続き。時間がかかるならカット繋ぎ) | 結果が盤面に残る |
| 5 | 15s | Attention Inbox (右下ピル) を開いて承認に応える | 判断が要るものだけ集まる |
| 6 | 15s | サイドバーの別陣地をクリック → キャンバスがパン/ズームで移動 | 複数フォルダの横断俯瞰 |
| 7 | 10s | ターミナルタブを開いて生ログを見る | 中身はごまかしていない (本物のCLI) |

**撮影のコツ**: シーン1の「稼働中」状態を作るため、撮影前に2〜3体のエージェントに
時間のかかるタスク (リポジトリの調査など) を渡しておく。

## プラットフォーム別カット

- **X (メイン)**: 45秒・16:9・字幕焼き込み。構成: シーン1 (3s) → 3 (10s) → 4 (5s) → 2 (8s) → 5 (5s) → ロゴ+「個人は無料」(3s)。冒頭の字幕: 「AIエージェント3体動かすと、探す時間の方が長くなる」
- **LinkedIn**: 60〜90秒。Xカット + シーン6・7を追加し、字幕をですます調に
- **Instagram/Facebook**: Xカットを1:1センタークロップで流用 (低工数)
- **README/LP用GIF**: シーン3→4のみ、12fps・幅720px

## ffmpeg 変換プリセット (撮影後にClaude側で実行)

```bash
# X/LinkedIn 用 (1080p, H.264)
ffmpeg -i raw.mp4 -vf "scale=1920:-2" -c:v libx264 -crf 20 -pix_fmt yuv420p -movflags +faststart out_x.mp4
# 1.5倍速 (待ち時間の圧縮)
ffmpeg -i raw.mp4 -vf "setpts=PTS/1.5" -an fast.mp4
# Instagram 1:1
ffmpeg -i out_x.mp4 -vf "crop=ih:ih" -c:v libx264 -crf 20 out_ig.mp4
# README 用 GIF
ffmpeg -i raw.mp4 -vf "fps=12,scale=720:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" out.gif
```
