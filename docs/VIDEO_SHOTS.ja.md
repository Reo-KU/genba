# 宣伝動画 撮影台本 — 2026-08-09

> 誇張禁止 (NEXT.ja.md §2④): 実演できる機能だけ。vault検索・スケジュール実行等の未実装機能は映さない・言わない。
> ターゲット: **2社以上のAI CLI併用 × 3体以上同時 × 複数フォルダ**の人。1行目で名指しする。

## 撮り方 (内蔵レコーダー)

MAOに内蔵したウィンドウレコーダーで撮る (アプリのウィンドウだけが映る。デスクトップ・通知・
Dockは映らない。録画中はオレンジの疑似カーソルとRECバッジが表示される)。

- 録画開始はClaude Code側から操作するので、**「シーン◯、いくよ」と言うだけでよい**。
  5秒後に録画が始まり、指定秒数で自動停止・mp4化される (`~/Desktop/mao-demo/raw/`)。
- 撮る前にウィンドウをできるだけ大きく (フルスクリーン推奨)。
- 言語は日本語UIのまま (英語版は後日UIを切り替えて撮り直す)。

## 撮影用ワークスペース (実データを映さないための隔離)

**実務の陣地は撮らない。** エージェントのログには指示文がそのまま映るため、事業内容が
流出する (2026-08-09 の初回シーン2でボツにした実例あり)。撮影は専用フォルダで行う:

```
~/Desktop/mao-demo/workspace/
  recipe-site/     README.md, app.js (TODO/FIXME コメント入り), src/data/recipes.json
  invoice-tool/    README.md, main.py (TODO 入り), requirements.txt
```

中身は公開前提で用意した小さなダミープロジェクト。README にセットアップ手順、
コードに TODO/FIXME を仕込んであるので、後述のタスクが**実際に意味のある応答**を返す。

## シーン一覧 (素材は長めに撮って編集で切る)

| # | 秒数 | 操作 | 見せたいもの |
|---|---|---|---|
| 1 | 20s | 陣地の「+ エージェント」→ 種類 (claude) を選ぶ → カードが生えて陣地に入る。もう1体、別ベンダー (codex 等) も追加 | **追加が数クリック**。working directory が陣地のフォルダに自動で決まる |
| 2 | 25s | 付箋を貼る → タスクを打つ (下記) → エージェントカードにドラッグして重ねる | 「貼る→渡す」だけ。ドラッグの瞬間がこの動画の主役 |
| 3 | 20s | **冒頭に「結果が返った付箋」を置く** (TODO一覧の表が書き込まれた状態を2〜3秒) → 担当カードをクリック → Inspector+生ログ → 閉じる | 結果が盤面に残る + 本物のCLIが動いた証拠。俯瞰→個体まで2クリック |
| 4 | 20s | recipe-site の **codex** にも付箋 (`READMEを3行に要約して`) を渡し、2陣地が同時に光っている状態を引きで見せる | **複数フォルダ × 複数ベンダー同時**。MAOの存在理由そのもの |
| 5 | 15s | Attention Inbox (右下ピル) を開く / サイドバーで別陣地へ移動 | 判断が要るものだけ集まる。横断の移動 |

**撮影のコツ**: 操作はゆっくり (1操作ごとに1秒止める)。15fps なので速い操作は飛ぶ。

## 付箋に打ち込む内容 (短く・無害・結果が絵になる)

タイプ時間を短くするため**20文字以内**に。すべて上のダミープロジェクトで意味を持つ。

| 陣地 | 打ち込む文 | なぜこれか |
|---|---|---|
| recipe-site | `READMEを3行に要約して` | 最速で返る (10〜20秒)。結果が付箋に収まる長さ |
| invoice-tool | `TODOを全部探して一覧にして` | 走査している感が出る。結果が箇条書きで絵になる |
| (予備) | `依存の古いものを調べて` | 少し長く走るのでシーン3の「稼働中」を作りやすい |

避けるもの: 実事業の指示、社名・製品名、長文、返答が10秒未満で終わる自明なもの
(「hello」等は本物っぽさが消える)。

## プラットフォーム別カット

- **X (メイン)**: 45秒・16:9・字幕焼き込み。構成: シーン1 (3s) → 3 (10s) → 4 (5s) → 2 (8s) → 5 (5s) → ロゴ+「個人は無料」(3s)。冒頭の字幕: 「AIエージェント3体動かすと、探す時間の方が長くなる」
- **LinkedIn**: 60〜90秒。Xカット + シーン6・7を追加し、字幕をですます調に
- **Instagram/Facebook**: Xカットを1:1センタークロップで流用 (低工数)
- **README/LP用GIF**: シーン3→4のみ、12fps・幅720px

## ffmpeg 変換プリセット (撮影後にClaude側で実行)

```bash
# X/LinkedIn 用 (1080p, H.264)
ffmpeg -i raw.mp4 -vf "scale=1920:-2" -c:v libx264 -crf 20 -pix_fmt yuv420p -movflags +faststart out_x.mp4
# 1.5倍速 (待ち時間の圧縮)
ffmpeg -i raw.mp4 -vf "setpts=PTS/1.5" -an fast.mp4
# Instagram 1:1
ffmpeg -i out_x.mp4 -vf "crop=ih:ih" -c:v libx264 -crf 20 out_ig.mp4
# README 用 GIF
ffmpeg -i raw.mp4 -vf "fps=12,scale=720:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" out.gif
```
