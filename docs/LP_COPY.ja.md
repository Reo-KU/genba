## Hero

**見出し**: ターミナルのタブ探しは、もう終わり。

**サブ**: Claude・Codex・Gemini…複数のAIエージェントを同時に走らせると、
「今どれが・どこで・何をしてるか」が分からなくなる。MAOはフォルダの樹形図で
それを1枚に描く。動いているフォルダは光る。クリックすれば中が見える。

**CTA(1つだけ)**: **無料でダウンロード** → 小文字で「個人利用は無料・機能制限なし。
組織での利用は商用ライセンス」

**CTA直下**: 30秒デモGIF (音なしで成立): 3フォルダで同時作業 → 光るフォルダを
クリック → エージェントカードが並ぶ → 付箋をドラッグして渡す → Inboxで承認

## セクション構成

1. **Hero**(上記)
2. **デモ**: 「説明はしません。見てください。」動画のみ。
3. **課題の言語化**: 「エージェントを3体動かした日から、あなたの仕事は
   『指示すること』から『探すこと』に変わった。tmuxのタブ、ターミナルの
   ウィンドウ、どれが会社分析で、どれがLP修正だったか。」(実体験ベース)

5. **証言**: β利用者3名 (実名・具体的状況入り)。発売前に収集。
6. **競合比較表**: 行は「複数ベンダー」「フォルダ横断の俯瞰」「GUI」「個人無料」の
   4行だけ。列: ターミナル手動運用 / Claude Code Agent Teams / MAO
