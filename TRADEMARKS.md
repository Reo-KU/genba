Forks, derivatives, packages, websites, hosted services, and integrations must
not use names, logos, descriptions, domains, social handles, or visual branding
that would cause users to believe they are official Genba projects or are
endorsed by Reo Komai.

Examples of uses that require separate written permission:

- naming a hosted service "Genba Cloud" or a confusingly similar name;
- using "Genba" as the main name of a fork;
- using the official Genba name or logo as the primary branding for a derivative

- registering domains or social accounts that imply official Genba ownership.

## Fork Naming

If you publish a fork or derivative, choose a distinct name and clearly state
that it is not the official Genba project. A good description is:

