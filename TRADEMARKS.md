Forks, derivatives, packages, websites, hosted services, and integrations must
not use names, logos, descriptions, domains, social handles, or visual branding
that would cause users to believe they are official MAO projects or are
endorsed by Reo Komai.

Examples of uses that require separate written permission:

- naming a hosted service "MAO Cloud" or a confusingly similar name;
- using "MAO OS" as the main name of a fork;
- using the official MAO name or logo as the primary branding for a derivative

- publishing a package or app listing that implies official status; or
- registering domains or social accounts that imply official MAO ownership.

## Fork Naming

If you publish a fork or derivative, choose a distinct name and clearly state
that it is not the official MAO project. A good description is:

```text
This project is a fork of MAO and is not affiliated with or endorsed by Reo Komai.
```
