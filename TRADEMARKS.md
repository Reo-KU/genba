Forks, derivatives, packages, websites, hosted services, and integrations must
not use names, logos, descriptions, domains, social handles, or visual branding
that would cause users to believe they are official Seiton projects or are
endorsed by Reo Komai.

Examples of uses that require separate written permission:

- naming a hosted service "Seiton Cloud" or a confusingly similar name;
- using "Seiton" as the main name of a fork;
- using the official Seiton name or logo as the primary branding for a derivative

- registering domains or social accounts that imply official Seiton ownership.

## Fork Naming

If you publish a fork or derivative, choose a distinct name and clearly state
that it is not the official Seiton project. A good description is:

